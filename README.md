# 군 급식 식자재 안전 지키미 (베타)

바코드·사진 글자 인식·직접 입력으로 식품안전나라 회수·부적합 이력을 확인하고, 이상 품목을 묶어 보고하는 PC용 검수 도구입니다. 기획서: `PRD_군급식_식자재안전지키미_베타.md`

## 처음 한 번 준비

1. Python 3.10 이상을 설치합니다 (설치할 때 "Add python.exe to PATH" 체크).
2. `.env.example`을 복사해 이름을 `.env`로 바꾸고, **재발급한** 식품안전나라 인증키를 넣습니다.
   ```
   FOODSAFETY_KEY=새로_발급받은_키
   ```
3. 가입을 허용할 부대 코드는 `config/units.json`에 있습니다 (가상 코드 `A123`, `B456`, `C789`).

## 실행

`실행.cmd`를 두 번 누르면 검은 창이 뜨고 브라우저가 `http://localhost:8765`로 열립니다. 검은 창을 닫으면 프로그램이 꺼집니다. 이미 켜져 있으면 브라우저만 다시 엽니다.

- 켤 때와 켜 둔 동안 1시간마다 I0490·I2620·I2715 전체를 받아 PC에 저장하고, 조회는 저장본에서 합니다.
- 인터넷이 끊기면 마지막 저장본으로 계속 조회합니다.
- 이 PC(127.0.0.1)에서만 열립니다.

## 사진·음성

- **제품 사진:** 후보 카드와 PDF 보고서에 식품안전나라 제품 사진이 나옵니다. 한 번 받은 사진은 `data/img_cache/`에 남아 인터넷이 끊겨도 보입니다. 이용 조건 확인 전이므로 검수 확인용으로만 씁니다.
- **소리로 듣기:** 후보 카드·조회 결과·긴급 공지·보고 문구마다 "🔊 소리로 듣기" 버튼이 있고, "소리 멈춤"으로 멈춥니다. 검수 화면에서 "조회 결과 자동으로 소리로 듣기"를 켤 수 있습니다. 설정 > 읽어 주기 목소리에서 목소리·빠르기를 고르고 들어 볼 수 있습니다. 자연스러운 목소리(Edge의 선희·인준, Chrome의 Google 한국의)는 인터넷이 필요하고, Windows 기본 음성은 인터넷 없이 됩니다. 한국어 음성이 없으면 Windows 설정 > 시간 및 언어 > 음성에서 한국어를 추가하세요.
- **말로 입력:** 입력칸 옆 "음성" 버튼. Chrome·Edge에서 동작하며 음성이 브라우저 회사 서버로 전송되므로 인터넷이 필요합니다. 민감한 내용은 말하지 마세요.

## 폴더

| 경로 | 내용 |
|---|---|
| `app/server.py` | PC 내부 실행 프로그램 (화면 제공, 로그인, 보고 문구, CSV) |
| `app/foodsafety.py` | 자료 받기·저장본·검색·날짜 변환 |
| `app/store.py` | SQLite 저장 (사용자, 설정, 검수 기록, 자료 보관) |
| `static/` | 화면 (검수, 보고, 검수 기록, 설정, PDF 보고서) |
| `static/vendor/` | 바코드(ZXing)·글자 인식(Tesseract.js, 한국어 자료)·Pretendard 글꼴. 외부 CDN 없이 읽음 |
| `config/units.json` | 부대 코드 목록 |
| `config/categories.json` | 분류 목록과 앱 제안 규칙. "조건부 사용" 등 분류 추가 가능 |
| `data/` | 실행하면 생김. `app.db`(기록), `photos/`(첨부 사진) |

## 관리

- 비밀번호 분실: 프로그램을 끄고 `data/app.db`에서 해당 사용자를 지운 뒤 다시 가입합니다 (베타).
- 기록 백업: `data` 폴더를 통째로 복사합니다.
- 인증키는 `.env`에만 둡니다. 화면·기록·오류 문구·보고서에는 나오지 않습니다.
